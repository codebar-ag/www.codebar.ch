# Co-Working gallery images

Drop photos of the Oberwil co-working space here.

- File names: `01.webp` … `06.webp`
- Format: WebP preferred (JPEG also works if the filename in the markdown is updated)
- Recommended source size: ~1600 px wide, 4:3 aspect ratio
- Filenames are referenced from `content/co-working/{de_CH,en_CH}/page.md` under the `gallery:` key

The Impressions section on `/coworking` only renders entries whose file actually exists, so partial uploads (e.g. only 3 of 6) work fine — missing entries are silently skipped.
