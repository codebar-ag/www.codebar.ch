The latest release delivers numerous enhancements in the areas of e-invoice processing, IDP integration, analytics, as
well as security and configuration.

## E-Invoice Processing

Processing e-invoices is now significantly more efficient:

- Line items from e-invoices are automatically transferred into table fields – perfect for review and further
  processing.
- Attachments (e.g., PDF or XML) are displayed directly in the viewer – even for complex e-invoice formats.

## IDP Integration in DocuWare Cloud

With the new **“IDP”** module in the DocuWare configuration:

- You define for each configuration which classification and data extraction steps IDP should perform.
- The IDP configuration can be integrated into **Connect to Mail** – so that email attachments are classified and
  prepared for further processing even before being archived.

**Result:** Automated indexing and targeted document handling right at the point of email receipt.

## Analytics

With the new **Workflow Analytics API**, DocuWare data can be seamlessly transferred to leading analytics tools:

- Analyze processes, identify optimization potential, and make informed decisions.
- A **new Power BI connector** provides direct access to:
    - Data from the Workflow Analytics API
    - Archive data

**Perfect** for data-driven decisions and transparent workflows.
